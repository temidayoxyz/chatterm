# Code of Conduct

Chatterm is committed to a welcoming, harassment-free community for everyone, regardless of identity, background, experience, or ability.

Be considerate, disagree with ideas rather than people, respect boundaries, and give actionable feedback. Harassment, threats, discriminatory language, unwanted sexual attention, doxxing, and sustained disruption are not tolerated in project spaces.

Maintainers may edit or remove contributions and restrict participation when behavior is harmful. Report conduct concerns privately to the repository owner through their GitHub profile. Reports will be handled as confidentially and promptly as practical.

This policy applies in Chatterm repositories, issue trackers, reviews, discussions, and public events where someone represents the project.
